# DiPro definition of done

- Approved acceptance criteria are met and scope is respected.
- Existing DiPro conventions and module ownership are followed.
- Relevant focused tests are added/updated where a suitable test project exists.
- Narrow relevant verification is run, or the reason it could not be run is reported.
- Final report lists changed areas, exact commands/results, assumptions, and risks.
- No secrets or sensitive data are included.
