# Task briefs

Store approved task briefs here when work spans people, agents, or sessions. Record goal, acceptance criteria, scope, decisions, and handoffs. Templates are guidance, not authorization.

Use `TASK_BRIEF_TEMPLATE.md` for routine multi-handoff work. Use `CROSS_CUTTING_PLATFORM_CHANGE_TEMPLATE.md` for new modules, shared architecture libraries, or other platform changes that cross boundaries. Keep project-specific briefs in the project overlay, under `.ai/project/tasks/` when that directory exists.
